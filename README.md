## 🌟 관심사 / 兴趣爱好

### 🎬 중국 드라마 / 中国电视剧
- 다양한 장르의 중국 드라마를 즐겨 봅니다. (역사극, 로맨스, 무협 등)  
  喜欢看各种类型的中国电视剧，比如古装剧、爱情剧、武侠剧等。
- 드라마를 통해 중국어와 중국 문화를 함께 공부하고 있습니다.  
  通过电视剧学习中文和了解中国文化。

### 📖 사자성어 / 成语
- 중국의 사자성어(成语)를 공부하며 그 안에 담긴 유래와 지혜를 탐구하는 것을 좋아합니다.  
  喜欢学习中国的成语，探索成语背后的典故和智慧。
- 즐겨 찾는 사자성어 몇 가지:  
  几个我很喜欢的成语：
  | 성어 (成语) | 뜻 (含义) |
  |:---:|:---|
  | 塞翁失马 | 새옹지마 — 화가 복이 될 수도 있다는 뜻 |
  | 画蛇添足 | 화사첨족 — 쓸데없는 짓을 덧붙이다 |
  | 水滴石穿 | 수적석천 — 꾸준함이 결국 큰 결과를 만든다 |
